# QRShield-X

**Explainable Hybrid AI for Quishing Detection**

QRShield-X is a research-oriented system designed to detect and analyze
potential quishing threats using QR-code analysis, URL and domain
investigation, evidence assessment, controlled investigation, explainable
decision-making, and machine-learning-based detection.
